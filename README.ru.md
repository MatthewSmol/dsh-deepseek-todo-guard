# Сторож TODO

[English](README.md) · **Русский**

Плагин DeepSeek Harness, который держит плашку задач TODO над полем ввода
актуальной. Это **штатная панель DSH** (`@deepseek-ai/dsh-client-ui-conversation`,
`conversation.input.dock`, id `todo`): она показывает задачи текущего раунда и
читает проекцию `todos`, которую создаёт событие `todo/write`. Агент часто
забывает завести список или обновить его, поэтому плагин делает это сам.

## Что делает

Каждые 30 секунд (настраивается) сторож проходит по живым сессиям и:

| Ситуация | Действие |
|---|---|
| в текущем ходе списка нет | создаёт его по запросу человека |
| список остался от прошлого хода | заменяет актуальным |
| ход закончился, есть незавершённые | отмечает задачи выполненными |
| список в ходе есть и свеж | не трогает |

Каждая подсказка попадает в журнал: время, сессия (название или короткий id),
действие, источник формулировок и число задач. Панель «Сторож TODO» в левом
сайдбаре показывает последние 5 записей и обновляется каждые 5 секунд. Журнал
хранится в памяти и в `.nudges.json`, поэтому переживает перезапуск.

Своей панели над полем ввода плагин не рисует: он лишь пишет `todo/write` в том
же формате, что и инструмент агента `todo_write`. Новых типов событий он не
добавляет и агента не будит.

## Откуда берутся формулировки

- **Модель сессии** (по умолчанию): одноразовый вызов `ctx.llm` тем же маршрутом,
  что и основной запрос (`session.requestHeader().config`), не чаще одного раза
  в 60 секунд на сессию, с таймаутом 20 с и лимитом 400 токенов. Ответ — строгий
  JSON, который нормализуется (≤7 пунктов, ≤120 символов, без повторов, не
  больше одной задачи «в работе», если параллелизм запрещён).
- **Эвристика**: если модель недоступна, не настроена, не ответила вовремя или
  ответила мусором. Существующие формулировки сохраняются, статусы двигаются по
  прогрессу; если списка нет — пункты берутся из строк запроса.

Запись в лог делается только при реальном изменении списка.

## Установка

```bash
npm install && npm run build
```

Затем **Plugins → Add plugin** (или `install_bundle` для каталога
`/home/main/PluginTODO`) и **перезапуск `dsh web`**: bundle-патч и клиентская
половина применяются только при старте сервера.

## Настройка

```yaml
- id: todo-watch
  config:
    checkIntervalSeconds: 30    # 5–600
    staleAfterMinutes: 10       # 0 — не считать список устаревшим
    curator: llm                # llm | heuristic
    llmProvider: ''             # по умолчанию маршрут сессии
    llmModel: ''
    llmMinIntervalSeconds: 60
    llmTimeoutMs: 20000
    llmMaxOutputTokens: 400
    maxItems: 7
    allowParallelInProgress: true
    promoteCompletedOnTurnEnd: true
    includeSubagents: false
    historySize: 5              # записей в панели сайдбара (1–50)
```

`curator: heuristic` полностью отключает вызовы модели. Полное описание,
HTTP-эндпоинт и ограничения — в [docs/DETAIL.ru.md](docs/DETAIL.ru.md)
(English: [docs/DETAIL.md](docs/DETAIL.md)).

## Сборка и тесты

```bash
npm run typecheck
npm run build      # хост: tsc → terser; клиент: tsc → обёртка загрузчика → terser
npm test           # typecheck + 67 тестов
```

Размеры после минификации: хост ≈ 14.6 КБ, клиент ≈ 6.3 КБ.

## Языки интерфейса

Панель, пункт сайдбара и метаданные страницы плагина есть на **русском**,
**английском** и **китайском**. Активный язык следует за локалью GUI, поэтому
подпись в сайдбаре и строки панели переключаются без перезагрузки.
