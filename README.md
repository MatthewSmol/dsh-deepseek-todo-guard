# Сторож TODO

Плагин DeepSeek Harness: следит, чтобы у сессии был актуальный список TODO, и
подсказывает агенту обновить его. Добавляет пункт **«Сторож TODO»** в левый
сайдбар с панелью задач и журнала проверок.

## Что делает

- Пункт в левом сайдбаре и панель: список задач текущей сессии с прогрессом,
  итог последней проверки и её параметры.
- Каждые 30 секунд (значение настраивается) сторож проверяет живые сессии и
  при необходимости шлёт агенту одну подсказку — через `agent.inject`, то есть
  не будит простаивающую сессию.
- Каждая проверка записывается в лог сессии событием `todo-watch/check` и
  видна в панели.

| Причина | Условие |
|---|---|
| `stale` | список не обновлялся дольше `staleAfterMinutes` (по умолчанию 10 мин), агент простаивает |
| `all-completed` | все задачи отмечены выполненными, но в сессии осталась несобранная работа |
| `no-todo` | новый ход идёт без записи `todo_write` |

## Устройство

Пакет ставится двумя строками патча (`cordis.patch.yml`):

- `todo-write` (`@local/dsh-todo-watch`) — штатный инструмент `todo_write`
  из `@deepseek-ai/dsh-tool-todo` с тем же поведением и описанием для модели.
  Его модуль заодно объявляет события лога `todo/write` и `todo-watch/check`:
  DSH принимает запись события только если объявление загружено вместе с
  плагином.
- `todo-watch` (`@local/dsh-todo-watch/host`) — собственно сторож: единый
  таймер, чистые правила `src/watch/watcher.ts`, подсказки агенту и поток
  проверок для панели.

Патч заменяет строку `preset-standard`, потому что DSH не даёт плагину
добавить определение события в чужой модуль: в новом процессе
`@deepseek-ai/dsh-tool-todo` объявлен без `todo-watch/check`. Конфигурация
пресета повторяет штатную и сохраняет его состав; после установки плагина
пресет `standard` целиком принадлежит патчу этого пакета.

## Настройка

```yaml
- id: todo-watch
  config:
    checkIntervalSeconds: 30   # 5–600
    staleAfterMinutes: 10      # 0 — проверка устаревания выключена
    remindAllCompleted: true
    remindMissingList: true
    remindOnlyWhenIdle: true   # не спорить с работающим агентом
```

Значения вне диапазона корректируются. Подробности — в
[docs/DETAIL.md](docs/DETAIL.md).

## Сборка

```bash
npm install
npm run typecheck   # хост и клиент
npm run build       # tsc → terser (хост) → vite (esbuild minify) → проверки
npm test            # typecheck + node --test
```

Сборка печатает размеры до и после минификации и падает при нарушении
контракта клиента (нет IIFE, нет загрузчика модулей, нет встроенного CSS,
лишний React), при отсутствии объявлений событий и при превышении лимитов:
`dist/client.js` — 250 КБ, `dist/index.js` — 60 КБ.

Текущие размеры: `dist/client.js` ≈ 13 КБ (gzip ≈ 4,7 КБ), хост после terser —
≈ 6 КБ.
